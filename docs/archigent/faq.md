# 常見問題

## 安裝與啟動

### Windows SmartScreen 顯示「已保護您的電腦」

Windows 安裝程式目前尚未程式碼簽章。只有確認檔案來自專案團隊時，選擇「其他資訊 > 仍要執行」。若公司政策封鎖安裝程式，請洽詢 IT 管理員。

### 啟動 Agent 失敗

請依序檢查：
1. 檢查 Agent 供應商設定與登入狀態（設定 > Agent）
2. 查看下載或錯誤訊息；首次下載需要網路
3. 若使用 ChatGPT 方案，確認已在同一部電腦完成登入
4. 若使用 API 金鑰，確認金鑰顯示為已儲存

### 無法產生影像（渲染、燈光、立面研究）

影像產生需要 Gemini 或 OpenAI 的 API 金鑰，在設定中設定。ChatGPT 方案登入不包含影像產生。

| 錯誤 | 處理方式 |
|------|----------|
| Gemini 模型清單顯示備援 | 確認金鑰已儲存，選取「重新整理模型」，檢查帳戶、地區與網路 |
| `401` 或 `403` | 金鑰無效或權限不足，重新輸入金鑰 |
| `429` | 已達配額或速率限制，稍後再試或換模型 |
| 更新後無法產生 | 完全結束應用程式後重新開啟，確認金鑰 |

## 使用問題

### Agent 回應速度

取決於選擇的模型與思考強度、問題複雜度、網路連線品質與 AI 服務的負載。

### 引用了不存在的法規條文

AI 模型偶爾會產生不精確的引用。若已連接 ArchiLAW，引用檢查機制會標記可疑的引用。請務必對照原文確認重要的法規引用。

### 知識庫是否包含最新的法規修正？

ArchiLAW 知識庫每日自動更新。但從法規修正公布到系統收錄，通常有 1-3 天的延遲。如需確認最新修正，建議直接查閱政府法規資料庫。

### Revit / SketchUp 配對失敗

| 問題 | 處理方式 |
|------|----------|
| 擴充功能快照未到達 | 確認 Archigent 與主機應用程式在同一台電腦，重新配對 |
| 快照遭拒絕 | 配對可能過期、影像過大，或不是 PNG/JPEG 快照。重新配對或手動匯入 |
| 配對碼過期 | 須在五分鐘內使用新的配對碼 |
| Archigent 重新啟動 | 本機位址會改變，需重新連接 |

如擴充功能無法使用，可在 Revit 或 SketchUp 匯出 PNG/JPEG 視圖，再使用 Archigent 的「匯入影像」按鈕。

### 圖紙檢查無法傳送視覺檢查

請先框選標題欄範圍，並在「傳送前檢視」確認遮罩頁面。如需傳送未遮罩的圖紙，須在專案設定中明確啟用，並檢查會暴露的內容。

### 燈光結果不如預期

- 渲染圖中原有的日光（陽光照射的光斑）在轉換成夜間燈光後仍會淡淡可見；使用沒有直射陽光的渲染圖效果最好
- 燈光模擬是視覺結果，不含照度數值。照度計算請使用 DIALux 或 Relux

## 隱私與安全

### 資料保存在哪裡？

- 專案記錄、對話與文件保存在本機的 `archigen.sqlite`
- Agent 工作檔案位於 `projects/<id>/workspace/`
- 桌面版的 API 金鑰透過作業系統憑證服務加密儲存
- 瀏覽器畫布歷程及部分網頁設定留在該瀏覽器
- 匯出的檔案保存到你選擇的位置；Agent 工作目錄的檔案不會自動複製到 Revit 或 CAD

### 哪些資料會傳送給外部服務？

- AI 查詢與對話內容會傳送至你選擇的 AI 服務供應商
- 渲染、燈光等影像產生會將圖片傳送至 AI 服務
- 圖紙預設以遮罩方式傳送；「傳送未遮罩圖紙」是個別專案設定，變更及每次傳送都會留下紀錄
- ArchiLAW 查詢會傳送至 ArchiLAW 伺服器
- 每次傳送前都有核准機制，且每次圖片傳送都會記錄

### 可以在公司電腦上使用嗎？

可以。Archigent 不需要管理員權限即可安裝，且資料保存在本機。請另行備份原始圖紙。

## 回報問題

回報錯誤時，請使用底部的「日誌」面板複製遮蔽後的錯誤訊息。請提供：

- 應用程式版本與作業系統版本
- 選擇的服務供應商與模型
- 是否使用遮罩或參考影像
- 重現步驟

請勿在截圖或訊息中包含 API 金鑰、配對碼、客戶姓名或私人圖紙。
