# 常見問題

## 安裝與啟動

### 首次開啟 macOS 顯示「無法驗證開發者」

這是 macOS 的安全性機制。請前往「系統設定 > 隱私權與安全性」，找到 Archigent 的提示，點擊「仍要打開」。請先向專案團隊確認發行者。

### 啟動 Agent 失敗

請依序檢查：
1. Agent 供應商設定是否正確（Settings > Text and Agent）
2. 若使用 ChatGPT 方案，是否已完成登入
3. 若使用 API 金鑰，確認金鑰已儲存
4. 首次使用時需要網路下載執行環境，確認網路連線

### 無法產生影像（渲染、燈光、立面研究）

影像產生需要 Gemini 或 OpenAI 的 API 金鑰，在 Settings 中設定。ChatGPT 方案登入不包含影像產生。請確認金鑰已儲存、模型可用。

## 使用問題

### Agent 回應速度

回應速度取決於：
- 選擇的 AI 模型與思考強度
- 問題的複雜程度
- 網路連線品質與 AI 服務的負載

### 引用了不存在的法規條文

AI 模型偶爾會產生不精確的引用。若已連接 ArchiLAW，引用檢查機制會標記可疑的引用。請務必對照原文確認重要的法規引用。

### 知識庫是否包含最新的法規修正？

ArchiLAW 知識庫每日自動更新。但從法規修正公布到系統收錄，通常有 1-3 天的延遲。如需確認最新修正，建議直接查閱政府法規資料庫。

### Revit 配對失敗

請確認：
1. Archigent 與 Revit 在同一台電腦上執行
2. 在五分鐘內完成配對
3. 使用對應 Revit 年份的增益集
4. 如 Archigent 重新啟動，需要重新配對

### 圖紙檢查無法傳送視覺檢查

請先框選標題欄範圍，並檢查遮罩頁面。如需傳送未遮罩的圖紙，須在專案設定中明確啟用。

## 隱私與安全

### 資料保存在哪裡？

- 專案、對話記錄與文件保存在你的本機
- 桌面版的 API 金鑰透過作業系統憑證服務加密儲存
- Agent 操作均需核准，每次傳送都會記錄

### 哪些資料會傳送給外部服務？

- AI 查詢與對話內容會傳送至你選擇的 AI 服務供應商（OpenAI、Gemini 或 ChatGPT）
- 渲染、燈光等影像產生會將圖片傳送至 AI 服務
- 圖紙預設以遮罩方式傳送，隱藏標題欄
- ArchiLAW 查詢會傳送至 ArchiLAW 伺服器
- 每次傳送前都有核准機制

### 可以在公司電腦上使用嗎？

可以。Archigent 不需要管理員權限即可安裝（Windows 的 Agent 安全設定除外），且資料保存在本機。Windows 上建議執行一次安全設定以建立沙箱環境。

## 回報問題

回報錯誤時，請使用底部的 Logs 面板複製錯誤訊息。請提供：
- 應用程式版本與作業系統版本
- 選擇的服務供應商與模型
- 重現步驟

請勿在截圖或訊息中包含 API 金鑰、配對碼、客戶姓名或私人圖紙。
