# 安裝與設定

::: info 測試版 (Beta)
目前為受邀測試版本，安裝檔案由管理員提供。
:::

## 下載

測試期間，請向管理員取得適合你作業系統的安裝檔案。

## 安裝步驟

### macOS

1. 開啟下載的 `.dmg` 檔案
2. 將 Archigent 拖曳至「應用程式」資料夾
3. 首次開啟時，macOS 可能會顯示安全性警告
4. 前往「系統設定 > 隱私權與安全性」，點擊「仍要打開」

### Windows

1. 執行下載的安裝程式
2. 依照安裝精靈的指示完成安裝
3. 安裝完成後，從開始選單或桌面捷徑啟動

### Linux

1. 依發行版使用對應的套件格式安裝
2. 安裝完成後，從應用程式選單啟動

## 初始設定

### 1. 連接知識庫

首次啟動後，需要設定 ArchiLAW 知識庫的連接：

1. 開啟設定頁面
2. 在「知識庫」區段輸入連接資訊（由管理員提供）
3. 點擊「連接」確認

### 2. 選擇 AI 模型

Archigent 支援多種 AI 模型：

| 選項 | 說明 |
|------|------|
| 預設模型 | 測試版內建，無需額外設定 |
| 自訂模型 | 可設定自己的 API 金鑰使用其他模型 |
| 專用模型 | 即將推出，針對建築領域最佳化 |

### 3. 介面語言

Archigent 介面預設為繁體中文。可在設定中切換其他語言。

## 更新

測試版更新由管理員通知，下載新版本覆蓋安裝即可。正式版將支援自動更新。
