## 安裝注意事項

### macOS

Mac 應用程式已由 Apple 簽章及公證。第一次開啟時，macOS 會詢問是否開啟從網路下載的應用程式，請選擇「打開」。

### Windows

Windows 安裝程式目前尚未程式碼簽章。SmartScreen 可能顯示「Windows 已保護您的電腦」。只有確認檔案來自本頁或專案團隊時，才選擇「其他資訊 > 仍要執行」。若公司政策封鎖安裝程式，請洽詢 IT 管理員。

### 從 ArchiGen Studio 升級

軟體已改名為 Archigent。專案、設定與已儲存的金鑰都留在原處，會直接出現在 Archigent。

- **Mac**：安裝 Archigent.app 後，請結束舊程式，並從「應用程式」刪除 ArchiGen Studio.app
- **Windows**：安裝程式會直接取代舊版

請從軟體內重新安裝 SketchUp 與 Revit 外掛，外掛選單才會顯示 Archigent；重新安裝前，舊外掛仍可正常配對。

## ArchiLAW

ArchiLAW 目前為內部測試階段。

- **MCP 連接**：需取得存取金鑰，請洽開發團隊
- **Web App**：即將上線
- **專用模型**：建築領域專用語言模型開發中
