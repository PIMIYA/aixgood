# 使用說明

## 主要介面

啟動 Archigent 後，主介面包含：

- **對話面板**：與 AI 助理互動的主要區域
- **知識庫面板**：瀏覽法規來源與搜尋結果
- **工具列**：常用功能的快速存取

## 法規查詢

### 基本查詢

在對話面板中直接輸入法規問題：

```
室內裝修審查申請需要哪些文件？
```

AI 助理會搜尋知識庫，提供相關法規條文與分析。

### 指定範圍查詢

可以在問題中指定管轄範圍或法規類型：

```
台北市對於建築物外牆裝飾物的規定
```

```
建築技術規則中關於無障礙坡道的設計規範
```

### 追問與釐清

針對回答可以繼續追問，AI 會維持對話脈絡：

```
> 用戶：危老重建的容積獎勵怎麼計算？
> AI：（回答容積獎勵相關規定）
> 用戶：那如果是私有建築物呢？
> AI：（接續回答私有建築物的情況）
```

## 來源查看

每筆回答都附有法規來源引用：

1. 點擊回答中的來源標注
2. 展開來源面板查看完整條文
3. 點擊連結可跳轉至政府法規網站原文

## 鍵盤快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Enter` | 送出訊息 |
| `Shift + Enter` | 換行 |
| `Ctrl/Cmd + N` | 新對話 |
| `Ctrl/Cmd + ,` | 開啟設定 |

## 使用建議

1. **問題要具體**：「建築法第 73 條的使用執照規定」比「建築法」更能得到精確回答
2. **善用追問**：先問大方向，再針對細節追問
3. **注意來源**：確認回答引用的法規來源是否正確，特別是條號
4. **回報問題**：發現回答有誤時，使用回饋功能回報
