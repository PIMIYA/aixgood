# 使用說明

## 建立專案

1. 在首頁輸入專案名稱，選取「建立專案」
2. 從左側階段列表開啟任一階段
3. 中央顯示階段工具或檔案，右側為 Agent 與對話面板
4. 階段狀態不會限制切換，可自由在各階段之間跳轉

## 使用 Agent

### 啟動

選取 Agent 面板中的「啟動 Agent」。首次使用會下載並驗證執行環境。

### 對話與請求

- 每個階段提供建議請求，選取後會帶入訊息框（不會自動送出），可修改後再送出
- Agent 會根據目前階段的指引、專案規則與設定回答
- 可針對回答繼續追問，系統會保持對話脈絡

### Agent 設定

| 設定 | 說明 |
|------|------|
| 模型 | 選擇 AI 模型（Agent 啟動後可選） |
| 思考強度 | 調整推理深度 |
| 自動模式 | 「每次都問」（預設）/ 「自動：低風險」/ 「自動：完整」 |
| 先計畫 | Agent 先提出計畫，確認後才執行 |

「自動：低風險」會自動核准建立與修改 Agent 自己建立的 Revit/SketchUp 元素。ArchiLAW 查詢、付費出圖、刪除等操作一律需要核准。

### 核准機制

Agent 的每個操作都會顯示核准卡片，標明要執行的動作與受影響的檔案。請仔細檢查後選擇核准或拒絕。

### 附加檔案

拖放或選取 PNG、JPEG、PDF 檔案（15 MB 以內）加入專案。圖片傳送至 AI 模型時會記錄每次操作。

### 常用指令

全事務所共用的提示範本。輸入訊息後可存為常用指令，點選即可帶入。

## 各階段工作內容

| 階段 | Agent 可協助的工作 |
|------|-------------------|
| 手稿 | 整理版本、找出缺少的尺寸、依已知基地尺寸校正 |
| CAD | 建立圖層與標註、匯出 DWG/DXF/PDF、與手稿疊合比對 |
| 模型 | 讀取 Revit/SketchUp 模型、報告修改、提出版本化變更 |
| 圖紙 | 列出所需圖紙、檢查文字重疊/超出圖框/簡體字 |
| 數量造價 | 附來源的數量統計、獨立重算與差異報告 |
| 渲染 | 以提示詞與區域遮罩產生建築渲染圖 |
| 燈光 | 讀取平面圖與燈具表、模擬燈光配置 |

手稿、CAD、模型及數量造價目前以 Agent 輔助為主，尚無專用編輯面板。

## 獨立工具

### 渲染 (Render)

1. 從首頁開啟「渲染」，或在專案的「渲染」階段操作
2. 上傳基礎影像
3. 輸入建築設計提示詞
4. 可新增區域遮罩，只塗繪要修改的範圍，並為各區域輸入指示
5. 選擇 Gemini 或 OpenAI 產生渲染圖

### 立面研究 (Facade study)

1. 加入一張現有建築視角，與 2-5 張參考案例
2. 可輸入基地條件與設計標準
3. 選擇 1-3 個方案並產生
4. 系統以對齊分數評估結果：0.35 以上為「有效方案」，0.25-0.35 需確認量體，低於 0.25 無法使用

### 燈光 (Lighting)

1. 載入視點渲染圖與平面圖 PDF（天花平面，可加地坪平面）
2. 裁切平面圖範圍、設定相機位置與方向
3. 可匯入燈具表，搜尋缺少的燈具資料
4. 產生燈光模擬結果，預設保留渲染圖結構並轉移燈光效果
5. 使用方案複製功能比較不同燈光配置

燈光模擬是視覺結果，不含照度數值。照度計算請使用 DIALux 或 Relux。

### 圖紙檢查 (Sheet check)

匯入 PDF/PNG/JPG 圖紙，系統在本機檢查：
- 簡體中文字元
- 文字重疊
- 文字超出圖框

可選用 AI 視覺檢查（需框選標題欄）。結果可匯出為 Markdown 或 CSV。

## Revit / SketchUp 整合

### 視圖擷取

1. 安裝對應的擴充功能（SketchUp .rbz 或 Revit 增益集）
2. 在 Archigent 的「Connect companion」取得端點與配對碼
3. 在 Revit/SketchUp 輸入配對資訊
4. 擷取當前視圖，回到 Archigent 確認後使用

配對僅限同一台電腦，配對碼五分鐘內有效。截圖不要包含配對碼。

### 模型操作

Agent 可透過已配對的 Revit/SketchUp 擴充功能讀取與修改模型。每次操作都需要核准，寫入前會儲存版本。SketchUp 的批次修改可整批復原。

## 介面操作

- **收合面板**：階段列表與 Agent 面板都可收合，給中央工作區更大空間
- **Agent 面板寬度**：拖曳左邊緣調整，按兩下恢復預設
- **深色模式**：Settings > Appearance 可選擇跟隨系統、淺色或深色
- **桌面通知**：Settings > Notifications 可在 Agent 完成或需要核准時顯示桌面通知
