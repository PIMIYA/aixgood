# 使用說明

## 建立專案

1. 在首頁輸入專案名稱，選取「建立專案」
2. 從左側階段列表開啟任一階段
3. 中央顯示階段工具或檔案，右側有「Agent」與「對話」分頁
4. 階段狀態不會限制切換，可自由在各階段之間跳轉

## 使用 Agent

### 啟動與對話

選取 Agent 面板中的「啟動 Agent」。首次使用會下載並驗證其固定版本的 Codex，請等待進度顯示。

選取建議請求後，先修改訊息，再按「送出」；建議請求不會自動傳送。Agent 每輪都會取得目前階段指引、專案規則與設定。「中斷」可停止本輪，「停止」可結束 Agent 工作階段。

### Agent 設定

Agent 面板上方提供以下設定（Agent 啟動後可選）：

| 設定 | 說明 |
|------|------|
| 模型 | 選擇 AI 模型（相容端點的模型固定） |
| 思考強度 | 調整推理深度 |
| 自動模式 | 控制核准層級（見下方） |
| 先計畫 | Agent 先提出計畫、不做任何變更，按「依計畫執行」才開始 |

#### 自動模式

| 模式 | 說明 |
|------|------|
| 每次都問（預設） | 每個操作都需要核准 |
| 自動：低風險 | 自動核准建立與修改 Agent 自己建立的 Revit、SketchUp 元素 |
| 自動：完整 | 再加上匯出與專案規則 |

以下操作一律需要核准：自訂 C# 或 Ruby、ArchiLAW 查詢、付費出圖、刪除，以及 Codex 在沙箱外的指令。每輪最多自動核准 20 次，每次都會在活動紀錄顯示「自動核准」。

### 核准機制

核准卡片會顯示建議的指令、檔案變更、對外查詢或模型操作。檢查完整參數及受影響檔案，再選擇「核准」或「拒絕」。內容不清楚時，先拒絕並要求縮小範圍。

- ArchiLAW 查詢會顯示查詢文字或文件識別碼
- 執行 Revit 程式碼前應看到完整 C# 原始碼與雜湊值
- 不要核准將客戶姓名、聯絡資訊或案件細節傳給外部服務

### 對話管理

- **對話**列出之前的對話，啟動時會接續最近一次
- **+ 新對話**開始新的對話
- 更新改變 Agent 的工具後，較舊的對話不會自動接續

### 附加檔案與常用指令

- **附加檔案**（或拖放至訊息框）：加入 15 MB 以內的 PNG、JPEG、PDF 到專案資料夾
- **常用指令**：全事務所共用的提示範本，輸入訊息後可存為常用指令，點選即可帶入

## 各階段工作內容

| 階段 | Agent 可協助的工作 |
|------|-------------------|
| 手稿 | 整理版本、找出缺少的尺寸、依已知基地尺寸校正；確認假設與採用的手稿 |
| CAD | 建立毫米尺寸的圖層與標註、匯出 DWG/DXF/PDF、與手稿疊合比對；檢查推估尺寸與圖層名稱 |
| 模型 | 讀取配對的 Revit 或 SketchUp 模型、報告建築師新增的修改、提出版本化變更；核對版本及受影響元素後逐項核准寫入。SketchUp 的一批變更是一個復原步驟，任何失敗都會整批復原 |
| 圖紙 | 列出所需圖紙、逐張匯出並檢查文字重疊、超出圖框及簡體字；檢查標題欄與圖號 |
| 數量造價 | 附來源的數量統計、獨立重算與差異報告；檢查單價來源與標示的 AI 估價 |
| 渲染 | 說明必須保留的部分、基地條件與設計自由度；比較生成視圖及對位分數 |
| 燈光 | 讀取圖紙與燈具表、確認位置及可修改區域、比較方案 |

手稿、CAD、模型及數量造價目前提供階段指引，尚無專用編輯面板。Agent 可在專案工作目錄處理檔案；Revit 與 SketchUp 操作需要在「模型」階段配對外掛，並經明確核准。

## 獨立工具

### 渲染 (Render)

1. 從首頁開啟「渲染」，或在專案的「渲染」階段操作
2. 上傳基礎影像，輸入建築設計提示詞
3. 可新增區域遮罩，只塗繪要修改的範圍，並為各區域輸入指示
4. 選擇 Gemini 或 OpenAI 產生渲染圖
5. 檢查結果。只有在要以結果取代目前畫布影像時，才使用「設為基底影像」

### 立面研究 (Facade study)

1. 從首頁開啟「立面研究」，或在專案的「渲染」階段選擇「立面研究」分頁
2. 加入一張現有建築視角，與 2-5 張參考案例圖片（PNG、JPEG 或 WebP，每張不超過 20 MiB、單邊不超過 8192 像素，總大小不超過 35 MiB）
3. 視需要輸入基地條件與設計標準，選擇 Gemini 或 OpenAI，指定 1-3 個方案
4. 選擇「檢查後送出」，核對實際要傳送的圖片與指令。Gemini 使用所有參考圖；OpenAI 只使用前兩張
5. 比較結果：

| 對齊分數 | 標示 | 可使用 |
|----------|------|--------|
| 0.35 以上 | 有效方案 | 可直接使用與儲存 |
| 0.25 - 0.35 | 請確認量體 | 確認量體後可使用 |
| 低於 0.25 | 量體已變更 | 不可使用或儲存 |

### 燈光 (Lighting)

1. 載入視點渲染圖，開啟平面圖 PDF（天花平面，可加地坪平面）
2. 對每張圖：裁切渲染圖所看到的範圍（不含圖框與圖例），設定相機位置與方向
3. 可匯入燈具表（跨多張圖時逐張匯入，資料會依燈具編號合併）。「查詢」可在確認廠牌與型號後上網查詢缺少的資料
4. 選擇場景、產生燈光模擬

預設保留渲染圖結構並轉移燈光效果。若模型把空間改動到無法對齊，結果會被退回。

**比較方案**：使用「建立副本」嘗試不同配置，「比較」分頁並排顯示各方案最新結果。

**區域修改**：在結果上選取「設為基底影像」，塗繪要修改的區域，使用 Gemini 產生。只有塗繪區域會改變。

**燈具資料庫**：在「燈具」分頁選擇「燈具資料庫」，可依廠牌、型號或類型搜尋，手動新增或編輯，並用「新增至專案」指定給燈具編號。

燈光模擬是視覺結果，不含照度數值。照度計算請使用 DIALux 或 Relux。

### 圖紙檢查 (Sheet check)

匯入 PDF、PNG 或 JPG 圖紙。PDF 的文字檢查在本機進行：

- 簡體中文字元
- 文字重疊
- 文字超出自動偵測或手動畫定的圖框

選用視覺檢查時，先框選標題欄，選取「傳送前檢視」，逐頁確認遮罩影像及指示後再傳送。結果可匯出為 Markdown 或 CSV。

### Agent 影像工具

Agent 也可以直接操作專案中的檔案進行渲染、立面研究與圖紙檢查。核准前請檢查每張圖片預覽、路徑、完整指示與供應商。這些工具會依預覽原樣傳送視圖，不會遮蔽標題欄；若視圖包含私人圖面資訊，請拒絕。

## Revit / SketchUp 整合

### 視圖擷取

1. 安裝對應的擴充功能：
   - SketchUp（macOS/Windows）：安裝 `.rbz` 擴充功能
   - Revit 2025/2026（Windows）：解壓縮並執行 `install.ps1`
   - 桌面版內附安裝檔，可從「安裝外掛」連結下載
2. 在「控制中心」的「從 Revit/SketchUp 擷取」，選取「連接外掛程式」
3. 將面板顯示的端點與配對碼貼到擴充功能
4. 在 Revit/SketchUp 中擷取當前視圖
5. 回到 Archigent 檢查縮圖，選擇「在畫布中使用」或「捨棄」

配對僅限同一台電腦，配對碼五分鐘內有效，首次擷取後 12 小時內持續有效。重新啟動 Archigent 後需重新連接。截圖不要包含配對碼。

### 模型操作

Agent 可透過已配對的擴充功能讀取與修改 Revit/SketchUp 模型。每次寫入都需要核准，寫入前會儲存版本。Agent 建立的元素會記錄在追蹤清冊中；再次寫入前須報告建築師的修改。SketchUp 的一批變更是一個復原步驟，任何失敗都會整批復原。

## 對話助理與參考文件

**助理**（渲染與燈光工作區的對話泡泡圖示）用於快速詢問設計問題、討論提示詞：只回答、不會修改任何東西。它會參考目前的主提示詞、已核准的專案記憶與上傳的相關參考文件。不需要專案、ChatGPT 登入或 Revit，可用 Gemini 或 OpenAI。

回答中有建議的提示詞時，按「套用到提示詞」即可帶入畫布的提示詞欄。Agent 面板的「快速提問」分頁也開啟同一個輕量助理。

## 介面操作

- **收合面板**：用「階段」旁的按鈕收合階段列，Agent 面板右上角的按鈕收合 Agent 面板。收合後的階段列仍保留各階段的編號連結
- **Agent 面板寬度**：拖曳左側邊緣調整，按兩下恢復預設
- **專案規則**：新增、修改或移除簡短指示，Agent 建議的規則也需要核准
- **專案設定**：Agent 面板上方的調整按鈕，可設定設計標準、族群資料庫路徑及標題欄範圍
