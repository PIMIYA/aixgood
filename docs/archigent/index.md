## 什麼是 Archigent

Archigent（原 Archigen Studio）是一款建築專業 AI 助理桌面應用程式。它整合 ArchiLAW 知識庫，在本機端提供法規諮詢、文件分析與專案輔助功能。

## 主要特色

### 整合知識庫

- 內建 ArchiLAW 建築法規知識庫連接
- 即時查詢法規條文與解釋
- 自動引用來源，方便追溯原文

### 桌面端體驗

- 原生桌面應用程式，操作流暢
- 支援多視窗作業
- 離線部分功能可用

### 文件輔助

- 法規文件的快速查閱
- 協助整理法規適用分析
- 專案相關法規的彙整

### 專用模型

::: tip 即將推出
Archigent 專用語言模型正在開發中，將針對建築專業工作流程進行最佳化，提供更貼近實務的輔助功能。敬請期待。
:::

## 系統需求

| 項目 | 最低需求 |
|------|----------|
| 作業系統 | macOS 13+、Windows 10+、Linux（GNOME/KDE） |
| 記憶體 | 8 GB RAM |
| 磁碟空間 | 500 MB |
| 網路 | 需要網路連線以存取知識庫 |

## 與 ArchiLAW 的關係

Archigent 和 ArchiLAW Web App 共享同一套知識庫，差異在於使用介面：

| | ArchiLAW Web App | Archigent App |
|---|---|---|
| 使用方式 | 瀏覽器 | 桌面應用程式 |
| 適用場景 | 快速查詢、臨時查閱 | 深度工作、專案整合 |
| 安裝 | 不需安裝 | 需下載安裝 |
| 離線功能 | 無 | 部分功能可用 |
