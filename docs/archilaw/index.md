## 什麼是 ArchiLAW

ArchiLAW 是一套專為台灣建築法規設計的 AI 知識檢索服務。它將散布在各政府網站的法規、規則、函釋與官方網頁資料整合為單一知識庫，透過語意檢索與 AI 回答協助建築專業人員查詢法規。

## 知識庫涵蓋範圍

目前知識庫收錄超過 45,000 筆資料單元，來源包含：

| 來源 | 說明 |
|------|------|
| 中央法規 | 建築法、建築技術規則、各項管理辦法等（法務部全國法規資料庫） |
| 行政規則與函釋 | 內政部主管法規查詢系統（nlma）收錄之行政規則、函釋與解釋令 |
| 地方自治條例 | 直轄市、縣市建築管理自治條例與地方法規（持續擴充中） |
| 官方網頁資料 | 各級主管機關官方網站上的建築相關資料 |
| 實務參考 | 相關公會之實務手冊、講座資料與實務指引 |

知識庫每日自動更新，追蹤法規異動。系統也會記錄條文層級的變更明細。

## 使用方式

ArchiLAW 提供兩種主要存取方式：

### 1. MCP 協定連接

透過 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 連接，可在支援 MCP 的 AI 工具中直接使用 ArchiLAW 知識庫。已驗證支援 Claude（claude.ai）與 ChatGPT（chatgpt.com）。

[MCP 連接指南 →](./mcp-guide)

### 2. Web App

透過瀏覽器直接使用的網頁介面，提供完整的對話式查詢體驗，包含來源引用、引用檢查、網路搜尋、深度研究等進階功能。

[Web App 使用說明 →](./webapp)

### 3. 透過 Archigent 查詢

在 Archigent 桌面應用程式的專案中，Agent 可直接查詢 ArchiLAW 知識庫，將法規資訊整合到建築專案工作流程中。

[Archigent 介紹 →](/archigent/)

## 技術架構

- **檢索**: 向量語意檢索（RAG）架構，搭配 GPU 重排序模型提升準確度
- **更新**: 自動化每日更新，追蹤多個政府法規來源的異動
- **引用**: 每筆回答附帶法規來源引用與連結，可追溯原文
- **引用檢查**: 自動驗證 AI 回答中的法規引用是否正確
- **認證**: OAuth 認證機制，以受邀帳號存取
