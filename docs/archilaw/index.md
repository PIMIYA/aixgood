## 什麼是 ArchiLAW

ArchiLAW 是一套專為台灣建築法規設計的 AI 知識檢索服務。它將散布在各政府網站的法規、規則、函釋整合為單一知識庫，並透過 AI 技術提供語意檢索與回答。

## 知識庫涵蓋範圍

| 來源 | 說明 |
|------|------|
| 中央法規 | 建築法、建築技術規則、各項管理辦法等（法務部全國法規資料庫） |
| 行政規則 | 內政部主管法規查詢系統收錄之行政規則 |
| 地方自治條例 | 直轄市、縣市建築管理自治條例（持續擴充中） |
| 函釋與解釋 | 各級主管機關之函釋、解釋令 |
| 實務參考 | 建築師公會、相關公會之實務手冊與指引 |

## 使用方式

ArchiLAW 提供兩種主要存取方式：

### 1. MCP 協定連接

透過 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 連接，可在支援 MCP 的 AI 工具中直接使用 ArchiLAW 知識庫。

適用工具：Claude（claude.ai）、ChatGPT、支援 MCP 的其他 AI 客戶端。

[MCP 連接指南 →](./mcp-guide)

### 2. Web App

透過瀏覽器直接使用的網頁介面，提供對話式查詢體驗。

[Web App 使用說明 →](./webapp)

## 技術架構

- **知識庫**: 向量檢索（RAG）架構，搭配重排序模型提升準確度
- **更新**: 自動化每日更新，追蹤法規異動
- **隱私**: 查詢記錄僅存於本地端，不經過第三方伺服器
- **引用**: 每筆回答附帶法規來源引用，可追溯原文
