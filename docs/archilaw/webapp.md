# Web App 使用說明

::: info 測試版 (Beta)
Web App 目前為測試版本，介面與功能持續調整中。
:::

## 存取方式

Web App 透過瀏覽器使用，目前為受邀測試制。取得存取連結後，直接在瀏覽器中開啟即可。

## 介面概覽

### 主畫面

開啟 Web App 後，你會看到：

- **對話區域**：主要的問答介面，在此輸入法規問題
- **側邊欄**：法規來源列表與相關資訊
- **頂部導覽列**：切換不同功能頁面

### 提問與回答

1. 在對話框中輸入你的法規問題
2. 系統會搜尋知識庫，並以 AI 生成回答
3. 回答下方會列出引用的法規來源
4. 點擊來源連結可展開詳細資訊或跳轉至原文

### 來源面板

每筆回答的引用來源會顯示：

- 法規名稱
- 相關條號
- 來源類型（法律、行政規則、函釋等）
- 管轄層級（中央、地方）
- 可折疊/展開的詳細內容

### 最近更新

「最近更新」頁面顯示知識庫的法規異動紀錄，包含：

- 修正的法規名稱
- 異動類型（修正、新增、廢止）
- 條文層級的變更明細
- 異動日期

## 使用技巧

### 提問方式

**推薦：**
- 「室內裝修申請流程中，需要哪些專業技術人員簽章？」
- 「台北市對於既有建築物增設電梯的規定」
- 「危老重建申請容積獎勵需要哪些條件？」

**避免：**
- 過於籠統的問題（例如「建築法」）
- 一次問多個不相關的問題

### 追問

你可以針對前一個回答繼續追問，系統會保持對話脈絡：

1. 先問：「建築物室內裝修管理辦法的審查流程」
2. 再問：「如果是簡易室內裝修呢？」

## 回饋

使用過程中如果發現：
- 回答內容有誤
- 引用的法規不正確
- 缺少重要的相關法規

歡迎透過介面中的回饋功能回報，這將幫助我們持續改善服務品質。
