# Web App 使用說明

::: info 測試版 (Beta)
Web App 目前為測試版本，介面與功能持續調整中。
:::

## 存取方式

Web App 透過瀏覽器使用，目前為受邀測試制。取得存取連結後，直接在瀏覽器中開啟即可。支援桌面與行動裝置瀏覽器。

## 介面概覽

### 主畫面

開啟 Web App 後，主要介面包含：

- **對話區域**：主要的問答介面，在此輸入法規問題
- **側邊欄**：對話記錄列表，可切換不同對話
- **來源面板**：回答所引用的法規來源，可展開查看詳細內容
- **大綱面板**：長回答的段落導覽

### 字體大小

介面預設使用較大的文字（因應建築師閱讀需求），可在設定中切換標準、大、特大三種尺寸。

## 提問與回答

1. 在對話框中輸入你的法規問題
2. 系統會搜尋知識庫，並以 AI 生成回答
3. 回答下方會列出引用的法規來源
4. 點擊來源連結可展開詳細資訊或跳轉至政府法規網站原文

### 來源範圍

查詢時可選擇資料範圍，縮小檢索目標：

- **全部資料**：搜尋所有收錄的資料（預設）
- **法規條文**：僅搜尋法律與法規命令
- **函釋**：僅搜尋函釋與解釋令
- **地方實務**：僅搜尋地方自治條例與地方資料
- **官方網頁**：僅搜尋各機關官方網站資料

也可進一步指定特定縣市。

### 追問

你可以針對前一個回答繼續追問，系統會保持對話脈絡：

1. 先問：「建築物室內裝修管理辦法的審查流程」
2. 再問：「如果是簡易室內裝修呢？」

### 深度研究

針對複雜問題，可啟用深度研究模式進行更全面的檢索與分析。

### 思考層級

可調整 AI 的思考深度：較高的思考層級會讓 AI 進行更仔細的推理，但回答速度較慢。

## 來源面板

每筆回答的引用來源會顯示：

- 法規名稱
- 相關條號
- 來源類型標記（法規、地方資料、函釋、實務參考等）
- 管轄層級與機關名稱
- 修正日期
- 連結至原文網站
- 可折疊/展開的內容摘要

## 引用檢查

系統會自動檢查回答中的法規引用，標記已驗證與待確認的引用，協助你判斷引用的可靠度。

## 法規異動

「最近更新」頁面顯示知識庫的法規異動紀錄，包含：

- 修正的法規名稱
- 異動類型（修正、新增、廢止）
- 條文層級的變更明細
- 異動日期
- 尚未施行的公告草案

## 檔案上傳

可上傳文件作為查詢的補充資料。支援格式：

- 文件：PDF、Word (.docx)、Excel (.xlsx)、PowerPoint (.pptx)、ODT、RTF、CSV、純文字
- 圖片：PNG、JPEG、HEIC、WebP

## 表格與圖表

回答中如涉及比較或數據整理，系統可產生：

- 互動式表格
- Vega-Lite 圖表

## 回饋

使用過程中如果發現回答內容有誤或引用不正確：

- **評分**：對每則回答進行正面或負面評價
- **問題回報**：詳細描述問題與預期結果

回饋將幫助我們持續改善服務品質。
