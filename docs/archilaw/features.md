# 功能說明

## 語意檢索

ArchiLAW 的核心功能是語意檢索。與關鍵字搜尋不同，你可以用自然語言描述問題，系統會透過向量檢索與重排序模型找出最相關的法規條文。

**範例查詢：**

- 「室內裝修審查需要準備哪些文件？」
- 「建築物高度限制與容積率的關係」
- 「無障礙設施的坡道坡度規定」

### 來源範圍篩選

查詢時可指定資料範圍，縮小檢索目標：

| 範圍 | 說明 |
|------|------|
| 全部資料 | 搜尋所有收錄的資料（預設） |
| 法規條文 | 僅搜尋法律、法規命令與行政規則 |
| 函釋 | 僅搜尋各級機關之函釋與解釋令 |
| 地方實務 | 僅搜尋地方自治條例與地方實務資料 |
| 官方網頁 | 僅搜尋各機關官方網站資料 |

也可進一步指定管轄區域（例如僅查臺北市或高雄市的規定）。

## 引用與溯源

每筆回答都會標註法規來源，包含：

- 法規名稱與條號
- 來源類型（法律、行政規則、函釋、地方資料等）
- 管轄層級（中央或地方，含機關名稱）
- 最近修正日期
- 來源連結（可直接開啟政府法規網站原文）
- 相關條文摘要

## 引用檢查

回答中的法規引用會經過自動檢查：

- 驗證引用的法規是否確實存在於知識庫中
- 確認條號對應正確
- 標記可能有誤或需要進一步確認的引用
- 以不同顏色或標記區分已驗證與待確認的引用

## 網路搜尋

當知識庫內的資料不足以回答問題時，系統可搜尋官方網站補充最新資訊，搜尋結果會標註來源並註明「來自網路，未經查證」。

## 深度研究模式

針對複雜問題，可啟用深度研究模式。系統會進行更全面的檢索與分析，提供更完整的回答。

## 法規異動追蹤

系統每日自動追蹤法規異動，記錄：

- 新增或修正的法規
- 條文層級的變更細節（哪些條文被修正、新增或刪除）
- 修正日期與施行日期
- 公告草案（尚未正式施行的修正草案）

## 檔案上傳

Web App 支援上傳文件作為查詢的補充資料，支援格式包含：PDF、圖片（PNG、JPEG、HEIC、WebP）、Word、Excel、PowerPoint、ODT、RTF、CSV 與純文字。

## 表格與圖表

回答中如涉及比較或數據，系統可產生互動式表格與圖表（Vega-Lite），方便閱讀。

## 回饋機制

使用者可對每則回答評分，或回報錯誤（包含問題描述與預期結果），協助改善系統品質。

## 目前限制

::: warning 測試版限制
- 知識庫尚未涵蓋所有地方自治條例，持續擴充中
- 部分法規的最新修正版本可能有數日延遲
- AI 回答僅供參考，不構成法律意見
- 法規間的交叉引用可能不完整
- 網路搜尋結果未經查證，使用前請確認
:::
