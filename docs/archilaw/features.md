# 功能說明

## 法規檢索

ArchiLAW 的核心功能是語意檢索。與關鍵字搜尋不同，你可以用自然語言描述問題，系統會找出最相關的法規條文。

**範例查詢：**

- 「室內裝修審查需要準備哪些文件？」
- 「建築物高度限制與容積率的關係」
- 「無障礙設施的坡道坡度規定」

## 引用與溯源

每筆回答都會標註法規來源，包含：

- 法規名稱與條號
- 最近修正日期
- 來源連結（可直接開啟政府法規網站原文）

## 最近更新追蹤

系統每日自動追蹤法規異動，記錄：

- 新增或修正的法規
- 條文層級的變更細節（哪些條文被修正、新增或刪除）
- 修正日期與施行日期

## 引用檢查

回答中的法規引用會經過自動檢查，確保：

- 引用的法規確實存在於知識庫中
- 條號對應正確
- 標記可能需要進一步確認的引用

## 目前限制

::: warning 測試版限制
- 知識庫尚未涵蓋所有地方自治條例，持續擴充中
- 部分法規的最新修正版本可能有數日延遲
- AI 回答僅供參考，不構成法律意見
- 法規間的交叉引用（例如不同法規對同一事項的規定）可能不完整
:::
