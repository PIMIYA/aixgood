# MCP 連接指南

::: info 什麼是 MCP
[Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 是一種開放協定，讓 AI 工具可以連接外部知識來源。透過 MCP，你可以在 Claude、ChatGPT 等 AI 工具中直接查詢 ArchiLAW 知識庫。
:::

## 支援的客戶端

| 客戶端 | 支援狀態 |
|--------|----------|
| Claude (claude.ai) | 已驗證 |
| ChatGPT (chatgpt.com) | 已驗證 |
| 其他 MCP 客戶端 | 理論上相容，歡迎回報 |

## 連接步驟

### Claude (claude.ai)

1. 開啟 [claude.ai](https://claude.ai)
2. 在對話介面中，找到 MCP 伺服器設定（通常在設定或工具選單中）
3. 新增 MCP 伺服器，輸入 ArchiLAW 的連接資訊（請向管理員取得）
4. 連接成功後，即可在對話中直接查詢建築法規

### ChatGPT (chatgpt.com)

1. 開啟 [chatgpt.com](https://chatgpt.com)
2. 前往 Plugins > Add custom MCP server
3. 輸入 ArchiLAW 的連接資訊
4. 連接成功後，ChatGPT 即可使用 ArchiLAW 工具

## 可用的工具

連接後，AI 工具中會出現以下 ArchiLAW 工具：

### `ask` - 法規查詢

向知識庫提問，取得相關法規條文與 AI 分析。

**參數：**
- `question`（必填）：你的法規問題，使用自然語言描述

**範例：**
- 「建築物室內裝修管理辦法中，竣工查驗需要哪些文件？」
- 「台北市建築管理自治條例對於違建的處理規定」

### `search` - 關鍵字搜尋

直接搜尋知識庫中的法規條文。

**參數：**
- `query`（必填）：搜尋關鍵字或詞組

## 使用建議

1. **具體描述問題**：越具體的問題，回答越精確。比起「建築法規定」，「建築法對於建造執照申請期限的規定」會得到更好的結果。
2. **指定管轄範圍**：如果問題涉及特定縣市的地方規定，請在問題中註明。
3. **交叉驗證**：重要的法規適用判斷，建議對照政府法規資料庫原文確認。

## 疑難排解

| 問題 | 可能原因與解決方式 |
|------|-------------------|
| 連接失敗 | 確認網路連線正常，並檢查連接資訊是否正確 |
| 工具未出現 | 重新整理頁面，或重新連接 MCP 伺服器 |
| 回答與預期不符 | 嘗試更具體的描述，或拆解為多個小問題 |
