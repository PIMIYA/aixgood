# 常見問題

## 一般問題

### ArchiLAW 的法規資料多久更新一次？

知識庫每日自動更新，追蹤法務部全國法規資料庫、內政部主管法規查詢系統（nlma）、各地方政府法規系統及相關官方網站的異動。從法規修正公布到系統收錄，通常有 1-3 天的延遲。

### 回答可以作為法律依據嗎？

不可以。ArchiLAW 提供的回答僅供參考，不構成法律意見。實務應用請以政府公報及主管機關公告為準，必要時諮詢建築師或相關專業人員。

### 知識庫目前涵蓋哪些地方法規？

地方自治條例持續擴充中。可使用 MCP 的 `list_sources` 工具查看目前收錄的所有來源群組，或在 Web App 的範圍篩選中查看可用的縣市選項。

### 為什麼有些問題系統回答「查無相關法條」？

可能原因包含：
- 相關法規尚未收錄至知識庫
- 問題描述需要更具體的關鍵字
- 該事項屬於地方層級規定，而該地方法規尚未收錄

建議嘗試換個方式描述問題，或指定更具體的法規範圍。

### 回答中引用來源的不同標記代表什麼？

系統會自動檢查引用的正確性。已驗證的引用表示系統確認該法規存在且條號正確；待確認的引用表示可能需要進一步核實，建議對照原文確認。

## MCP 相關

### MCP 連接需要付費嗎？

測試期間 ArchiLAW 的 MCP 服務免費使用。但 AI 客戶端本身（如 Claude Pro、ChatGPT Plus）的訂閱費用由各平台收取。

### 需要帳號嗎？

是的。ArchiLAW 使用 OAuth 認證機制，需要受邀帳號才能存取。請向管理員申請。

### 可以同時在多個 AI 工具中使用嗎？

可以。ArchiLAW 的 MCP 服務可同時連接多個客戶端。

### 查詢突然出現格式錯誤？

ArchiLAW 更新後，已開著的對話可能記著舊版格式，常見錯誤訊息含有「additional properties」或「schema」。開一個新對話再試，或到連接器設定重新連接即可。

## Web App 相關

### 對話紀錄會被保存嗎？

對話紀錄保存於你的帳號下。清除瀏覽器資料不影響對話記錄，重新登入後仍可存取。

### 支援行動裝置嗎？

Web App 支援手機和平板瀏覽器，介面會自動適應螢幕大小。

### 可以上傳哪些格式的檔案？

支援 PDF、圖片（PNG、JPEG、HEIC、WebP）、Word (.docx)、Excel (.xlsx)、PowerPoint (.pptx)、ODT、RTF、CSV 與純文字檔案。
