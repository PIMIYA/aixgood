# 常見問題

## 一般問題

### ArchiLAW 的法規資料多久更新一次？

知識庫每日自動更新，追蹤中央法規資料庫（法務部）、內政部主管法規查詢系統及各地方政府法規系統的異動。

### 回答可以作為法律依據嗎？

不可以。ArchiLAW 提供的回答僅供參考，不構成法律意見。實務應用請以政府公報及主管機關公告為準，必要時諮詢建築師或相關專業人員。

### 知識庫目前涵蓋哪些地方自治條例？

目前已收錄台北市、桃園市、台中市、高雄市、新竹市、苗栗縣、南投縣、嘉義縣、台東縣、金門縣及連江縣等地方法規，並持續擴充中。

### 為什麼有些問題系統回答「查無相關法條」？

可能原因包含：
- 相關法規尚未收錄至知識庫
- 問題描述需要更具體的關鍵字
- 該事項屬於地方層級規定，而該地方法規尚未收錄

建議嘗試換個方式描述問題，或指定更具體的法規範圍。

## MCP 相關

### MCP 連接需要付費嗎？

測試期間 ArchiLAW 的 MCP 服務免費使用。但 AI 客戶端本身（如 Claude Pro、ChatGPT Plus）的訂閱費用由各平台收取。

### 可以同時在多個 AI 工具中使用嗎？

可以。ArchiLAW 的 MCP 服務可同時連接多個客戶端。

## Web App 相關

### 對話紀錄會被保存嗎？

對話紀錄僅保存在你的瀏覽器本地端，不會上傳至伺服器。清除瀏覽器資料會同時清除對話紀錄。

### 支援行動裝置嗎？

Web App 支援手機和平板瀏覽器，介面會自動適應螢幕大小。
