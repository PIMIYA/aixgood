## 關於 AIxGood 計畫

AIxGood 是洪建全基金會推動的計畫，探索 AI 技術在專業領域中的應用。目前提供兩項服務：

- **ArchiLAW** -- 台灣建築法規知識庫與 AI 檢索服務
- **Archigent** -- Agentic architecture design 桌面應用程式

兩者共享同一套法規知識庫。ArchiLAW 專注於法規檢索與問答；Archigent 是 agentic 架構設計工作台，Agent 直接操作模型、產出渲染圖、檢查圖紙、查詢法規，整合在建築師的設計流程中。

::: warning 測試版注意事項
本服務目前為測試版本（Beta），內容與功能持續開發中。法規資料僅供參考，實務應用請以政府公報及主管機關公告為準。
:::

::: tip 專用模型
建築領域專用語言模型正在開發中，推出後將提供更精確的法規理解與建築專業回答能力。
:::
