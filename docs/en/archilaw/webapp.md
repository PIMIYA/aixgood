# Web App Guide

::: info Beta
The Web App is in beta. The interface and features are under active development.
:::

## Access

The Web App runs in a browser and is currently available by invitation. Open the access link in your browser. Desktop and mobile browsers are both supported.

## Interface overview

### Main screen

The main interface includes:

- **Conversation area**: the primary Q&A interface where you type regulatory questions
- **Sidebar**: conversation history list for switching between conversations
- **Source panel**: regulatory sources cited in the answer, expandable for detail
- **Outline panel**: section navigation for long answers

### Font size

The interface defaults to a larger font (suited for architects' reading needs). You can switch between standard, large and extra-large in settings.

## Asking questions

1. Type a regulatory question in the input box
2. The system searches the knowledge base and generates an AI answer
3. Cited regulatory sources are listed below the answer
4. Select a source link to expand details or jump to the original text on the government site

### Source scope

You can narrow the search scope:

- **All sources**: search everything (default)
- **Statutes**: statutes and regulations only
- **Rulings**: rulings and interpretive orders only
- **Local practice**: municipal codes and local materials only
- **Government web**: government agency website content only

You can also specify a particular city or county.

### Follow-up questions

You can ask follow-up questions; the system maintains conversation context:

1. First ask: "What is the review process under the Interior Renovation Management Act?"
2. Then ask: "What about simplified interior renovation?"

### Deep research

For complex questions, enable deep research mode for a more thorough search and analysis.

### Reasoning level

You can adjust the AI's reasoning depth: higher levels produce more careful reasoning but slower answers.

## Source panel

Each answer's cited sources show:

- Statute name
- Related article numbers
- Source type label (statute, local data, ruling, practice reference, etc.)
- Jurisdiction level and agency name
- Amendment date
- Link to original text
- Collapsible content excerpt

## Citation checks

The system automatically checks citations in answers, marking verified and unverified citations to help you assess reliability.

## Regulatory changes

The "Recent updates" page shows the knowledge base's regulatory change log including:

- Amended statute names
- Change types (amendment, addition, repeal)
- Article-level change details
- Change dates
- Draft announcements not yet in force

## File upload

You can upload documents as supplementary material. Supported formats:

- Documents: PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), ODT, RTF, CSV, plain text
- Images: PNG, JPEG, HEIC, WebP

## Tables and charts

When an answer involves comparisons or data summaries, the system can generate:

- Interactive tables
- Vega-Lite charts

## Feedback

If you find errors in answers or incorrect citations:

- **Rating**: give positive or negative feedback on each answer
- **Problem report**: describe the problem and expected result in detail

Your feedback helps us continuously improve the service.
