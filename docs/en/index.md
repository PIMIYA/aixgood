## About the AIxGood Program

AIxGood is an initiative of the Hong Foundation exploring how AI can serve professional domains. It currently offers two services:

- **ArchiLAW** -- a Taiwan building-law knowledge base and AI retrieval service
- **Archigent** -- an agentic architecture design desktop application

Both share the same regulatory knowledge base. ArchiLAW focuses on statute retrieval and Q&A; Archigent is the agentic design workbench where the Agent operates models, produces renders, checks sheets and queries regulations as part of the architect's workflow.

::: warning Beta notice
This service is in beta. Content and features are under active development. Regulatory data is for reference only -- consult official gazettes and competent authorities for practice.
:::

::: tip Domain-specific model
A building-domain language model is under development and will improve regulatory comprehension and professional answers when released.
:::
